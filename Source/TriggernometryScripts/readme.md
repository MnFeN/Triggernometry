# TriggernometryScripting Project Overview

The TriggernometryScripting project provides an IntelliSense-enabled environment
for writing scripts. It does not build and produces no output files.

## UserScripts Folder

`UserScripts` stores user-created script files.  
The folder is included in the repository, but its contents are ignored by Git.

- This project does not execute scripts or produce DLLs

- All files inside `UserScripts` are ignored and do not affect the repository
